# My Shop

A web based e-commerce platform.

React + Vite storefront with Supabase (database + auth), Google sign-in, Mailgun confirmation emails, hosted on Vercel.

* Product requirements: PRD.md
* Architecture and build order (for the coding agent): AGENTS.md
* Manual setup steps: SETUP.md

Run locally with `vercel dev` once the API exists (Phase 6); before that `npm run dev` is enough.
